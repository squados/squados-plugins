# Comparação de direções visuais

Use uma galeria quando a pessoa precisar escolher entre alternativas. Mostre as opções no mesmo conteúdo, escala e contexto. Para opções de layout, conserve a identidade visual. Para opções de identidade, compare como cada linguagem organiza o mesmo conteúdo.

Nomeie as opções pelo que muda para quem olha ou usa. Abra cada versão e confira leitura, consistência e comportamento antes de apresentar. Mostre diferenças que afetam a decisão. Incorpore a direção escolhida ao projeto.
