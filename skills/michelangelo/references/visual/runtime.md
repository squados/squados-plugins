# Inspeção visual no Studio

Use as ferramentas de captura e render disponíveis no backend que acessa os arquivos. Abra HTML local diretamente quando funcionar. Para layout web, inspecione o navegador na dimensão relevante. Para slide ou documento, confira a saída renderizada pelo aplicativo ou pelo conversor disponível. Diga quais telas, páginas e estados foram inspecionados.
