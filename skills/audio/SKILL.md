# Áudio, Voz e Transcrição

Reconheça se o resultado é texto, locução, música ou análise de áudio. Confirme idioma, falantes, qualidade e formato necessários; preserve o material original. Use os meios disponíveis, sem supor API paga ou modelo local instalado.

Transcrição exige fidelidade: marque trechos incertos, mantenha nomes, negações e números e use timestamps quando a tarefa pedir. Uma voz gerada não é transcrição. Editar vídeo e motion pertence a Tarantino; aqui ficam as capacidades de áudio independentes.
