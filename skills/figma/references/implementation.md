# Implementação a partir de Figma

Leia contexto estrutural e screenshot do nó solicitado. Mapeie tokens, espaçamento, imagens, fontes, componentes e comportamento responsivo para a stack real do projeto. Procure primeiro componentes e estilos existentes.

Use assets exportados pela conexão quando permitidos; não invente ícones ou placeholders para materiais disponíveis. Implemente a hierarquia e os estados, compare a renderização com a referência e registre diferenças. Michelangelo pode conduzir decisões visuais abertas; uma referência aprovada deve conservar sua identidade.
