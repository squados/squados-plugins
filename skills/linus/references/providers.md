# APIs, IA e provedores

Leia a versão da dependência no projeto e a documentação oficial correspondente. Para OpenAI, use documentação oficial atual e o contrato da API pretendida; não importe configuração pessoal de Codex. Para Hugging Face, tokenizers, avaliação, geração estruturada e Pinecone, use as referências específicas disponíveis neste pacote.

Modelos, credenciais e hardware são requisitos distintos. Declare conjunto de avaliação, versão, configuração, custo e limitação; um resultado de teste isolado não comprova qualidade geral. Não publique token, arquivo privado ou dataset em um hub ao executar uma simples análise.
