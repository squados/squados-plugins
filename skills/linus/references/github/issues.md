# Issues

Leia `gh issue view NUMERO --comments` e o contexto do repositório. Procure duplicatas antes de criar uma issue. Separe relato, reprodução, evidência, esperado, observado e impacto; uma hipótese não é diagnóstico.

Para criar/editar, escreva o corpo exato em arquivo temporário e use --body-file. Preserve rótulos, responsáveis, projetos e critérios relevantes. Depois de uma mutação autorizada, releia o objeto e entregue o link real.
