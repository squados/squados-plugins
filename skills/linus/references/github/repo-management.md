# Repositórios e releases

Identifique owner, repositório, host e branch pelo projeto real. Use gh repo view, gh repo list e gh release view/list para consultar. Clone, fork, visibilidade, proteção de branch, secrets, releases e exclusão são operações diferentes, com efeitos próprios.

Antes de mudança remota, confirme o alvo e o escopo autorizado. Não altere configuração global, remotes ou autenticação para resolver um erro pontual. Verifique o objeto retornado e registre o URL/ID da operação.
