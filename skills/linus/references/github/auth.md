# Autenticação

Confira `gh auth status` e o host da operação. Use a conta já autenticada e o mecanismo seguro da plataforma. Se faltar acesso, conduza a conexão/login suportado e retome o trabalho; não peça à pessoa comandos ou tokens no chat.

Não exporte credenciais para curl, reconfigure Git globalmente ou crie chaves SSH por hábito. A operação deve usar o projeto e a conta autorizados. Erros de escopo, repositório ausente e rede são causas distintas. Para Git, preserve o helper de credenciais já configurado.
