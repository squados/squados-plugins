# Pull requests

Leia instruções, estado de Git e referência de base antes de alterar. Preserve WIP e o fluxo do projeto. Uma tarefa não autoriza push, merge ou publicação por hábito.

Use `gh pr view` e `gh pr checks` para o estado real. Prepare título e corpo sobre o problema e o comportamento final; passe texto multilinha por --body-file. Confira diff, commits e checks contra a base correta. Rascunho, revisão, CI verde e merge são estados diferentes; uma promessa de acompanhar CI exige execução que realmente continue ativa.
