# Template do Studio

Pulo Alto é um jogo original do SquadOS, escrito em Canvas 2D sem bibliotecas nem build.
Código e interface: [MIT](LICENSE). Sprites, vetores e sons em `assets/`: Kenney, [CC0](LICENSE-Kenney.txt).
O kit em `assets/` traz o New Platformer Pack completo; o tema fica em `THEME`, no topo de game.js.

Copie este pacote inteiro para o projeto antes de editar; nunca altere o original.
Não há instalação: sirva a pasta por HTTP ou abra index.html. A fase fica em level.js.
A prévia PNG é um frame real do jogo; sem autenticação ou serviços externos.
