# Template do Studio

Simulador de Cidades é uma adaptação SquadOS da base identificada em UPSTREAM.md.
As fontes, recursos e licenças originais estão neste pacote e devem acompanhar suas cópias.
Termos identificados: GPL-3.0 and Micropolis terms; see LICENSE and COPYING.

Copie este pacote inteiro para o projeto antes de editar; nunca altere o original.
Execute npm ci e npm run build na cópia. O build recompila a simulação e mantém a entrada na raiz; sirva este diretório por HTTP.
A prévia PNG corresponde ao jogo aprovado; sem autenticação ou serviços externos.
