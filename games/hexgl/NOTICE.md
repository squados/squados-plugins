# Template do Studio

Corrida Espacial é uma adaptação SquadOS da base identificada em UPSTREAM.md.
As fontes, recursos e licenças originais estão neste pacote e devem acompanhar suas cópias.
Termos identificados: MIT; code exceptions CC BY-NC 3.0; audio CC BY3.0.

Copie este pacote inteiro para o projeto antes de editar; nunca altere o original.
Execute npm ci e npm run build na cópia. O build copia o jogo estático para dist/; sirva dist/ por HTTP.
A prévia PNG corresponde ao jogo aprovado; sem autenticação ou serviços externos.
Há exceções CC BY-NC 3.0 no código: esta integração local não resolve a autorização para distribuir ou usar comercialmente. Consulte README.md, UPSTREAM.md e os cabeçalhos antes de publicar.
