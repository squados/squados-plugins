# Template do Studio

Cidade Sem Lei é um jogo original do SquadOS, escrito sobre Three.js e montado com Vite.
Código e interface: [MIT](LICENSE). Three.js: [MIT](LICENSE-three.txt), embutido no build `play/`.
Modelos 3D e sons em `public/assets/`: Kenney, [CC0](LICENSE-Kenney.txt).

Copie este pacote inteiro para o projeto antes de editar; nunca altere o original.
Execute npm ci e npm run build na cópia. O build grava o jogo estático em play/; sirva o pacote por HTTP.
A prévia PNG é um frame real do jogo; sem autenticação ou serviços externos.
