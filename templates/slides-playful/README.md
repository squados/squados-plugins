# Divertido / Playful

Layout de capa aprovado em 24/10/2026: uma capa 1280×720 feita só de HTML/CSS, sem imagens nem scripts.

## Uso e personalização

Copie o pacote inteiro para a pasta de trabalho e abra presentation.html. Preserve LICENSE e os IDs dos elementos. O slide usa o ID playful-cover. Marca, etiqueta, título em duas linhas com marca-texto, subtítulo, data e local são texto real no HTML. Círculos, pílula, pontos e a linha ondulada são CSS e SVG inline. Acrescente slides quando solicitados, mantendo o creme de fundo, o coral, o amarelo, o verde-menta, o roxo, a tipografia pesada e os botões com sombra sólida.

Fontes locais: Segoe UI Black e Segoe UI, com Arial Black, Helvetica e Arial como reserva. Nenhuma fonte é incluída; outra fonte pode mudar as proporções.

preview.png é a captura do HTML. Empresa, data e local são exemplos.

## English

A single 1280×720 playful cover built only with HTML/CSS and inline SVG: no images, no scripts. Copy the complete package before editing; keep LICENSE and the stable IDs (cover ID playful-cover). Brand, tag, highlighted two-line title, subtitle, date and place are HTML text. Add slides on request using the same cream, coral, yellow, mint and purple palette, heavy type and solid-shadow chips. Local fonts: Segoe UI Black and Segoe UI with Arial Black, Helvetica and Arial fallbacks. preview.png renders the actual source.
