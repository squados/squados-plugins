# Futurista / Futuristic

Layout de capa aprovado em 24/10/2026: uma capa 1280×720 feita só de HTML/CSS, sem imagens nem scripts.

## Uso e personalização

Copie o pacote inteiro para a pasta de trabalho e abra presentation.html. Preserve LICENSE e os IDs dos elementos. O slide usa o ID futuristic-cover. Marca, data e versão, chamada, título em duas linhas (a segunda em gradiente), subtítulo, apresentação e página são texto real no HTML. O anel luminoso, a grade em perspectiva, o horizonte e as marcas de canto são CSS puro. Acrescente slides quando solicitados, mantendo o fundo quase preto, o ciano, o violeta e o rosa em brilho, os rótulos monoespaçados e as marcas de canto.

Fontes locais: Bahnschrift (títulos) e Cascadia Mono (rótulos), com Segoe UI, Helvetica, Arial, Consolas e Menlo como reserva. Nenhuma fonte é incluída; outra fonte pode mudar as proporções.

preview.png é a captura do HTML. Empresa, datas e nomes são exemplos.

## English

A single 1280×720 futuristic cover built only with HTML/CSS: no images, no scripts. Copy the complete package before editing; keep LICENSE and the stable IDs (cover ID futuristic-cover). Brand, date, kicker, two-line title with a gradient second line, subtitle, presenter and page are HTML text; the glowing ring, perspective grid, horizon and corner marks are pure CSS. Add slides on request using the same near-black, cyan, violet and pink glow palette, monospaced labels and corner marks. Local fonts: Bahnschrift and Cascadia Mono with Segoe UI, Helvetica, Arial, Consolas and Menlo fallbacks. preview.png renders the actual source.
