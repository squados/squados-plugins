# Editorial

Layout de capa aprovado em 24/10/2026: uma capa 1280×720 feita só de HTML/CSS, sem imagens nem scripts.

## Uso e personalização

Copie o pacote inteiro para a pasta de trabalho e abra presentation.html. Preserve LICENSE e os IDs dos elementos. O slide usa o ID editorial-cover. Cabeçalho de revista, edição, data, chamada, título em duas linhas (a segunda em itálico), texto de abertura com capitular, sumário "Nesta edição", autoria e página são texto real no HTML. O numeral vazado ao fundo é tipografia em CSS. Acrescente slides quando solicitados, mantendo o papel marfim, o preto, o vermelho de destaque, a serifa nos títulos e os fios finos.

Fontes locais: Georgia (títulos e texto) e Segoe UI (rótulos), com Times New Roman, Helvetica e Arial como reserva. Nenhuma fonte é incluída; outra fonte pode mudar as proporções.

preview.png é a captura do HTML. Publicação, autoria e textos são exemplos.
