# Catalog

Base demonstrativa com conteúdo genérico. Adapte uma cópia; conserve esta base.

Instale com npm ci; npm start inicia o Expo; npm run typecheck valida o projeto; npm run build:web gera prévia web. A renderização web não comprova execução em aparelho.

Source: https://github.com/expo/expo/tree/main/templates/expo-template-blank-typescript; create-expo-app 5.0.0. Código adaptado do SquadOS Apache-2.0; licença upstream conservada quando houver. Nenhum serviço/segredo configurado.
