# Corporativo / Corporate

Layout de capa aprovado em 24/10/2026: uma capa 1280×720 feita só de HTML/CSS, sem imagens nem scripts.

## Uso e personalização

Copie o pacote inteiro para a pasta de trabalho e abra presentation.html. Preserve LICENSE e os IDs dos elementos. O slide usa o ID corporate-cover. Marca, data, chamada, título em duas linhas, subtítulo, apresentador e número da página são texto real no HTML. O painel de formas geométricas à direita é CSS puro: troque cores e formas pelas classes. Acrescente slides quando solicitados, mantendo a paleta azul-marinho e cobalto, a tipografia sem serifa e o grid.

Fontes locais: Segoe UI, com Helvetica Neue, Helvetica e Arial como reserva. Nenhuma fonte é incluída; outra fonte pode mudar as proporções.

preview.png é a captura do HTML. Empresas, datas e nomes são exemplos.

## English
