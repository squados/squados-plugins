# Proposta comercial / Commercial proposal

Template aprovado em 22/10/2026: somente uma capa, em HTML/CSS, com todos os textos editáveis.

## Uso e personalização

Copie o pacote inteiro para a pasta de trabalho e abra presentation.html. Preserve assets/, LICENSE e os IDs dos elementos. O slide mede 1280×720 e usa o ID commercial-cover. Títulos, empresa, período e rodapés são texto real no HTML; a imagem em assets/commercial.png contém somente a arte de fundo. Ajuste conteúdo e quebras de linha na cópia. Acrescente slides quando solicitados.

Fontes locais: Times New Roman; Segoe UI. Fontes não incluídas; os fallbacks definidos no CSS podem mudar as proporções em outro computador. Esta capa não depende de rede, scripts ou servidor.

preview.png é a captura do HTML aprovado. Dados, empresas e datas são exemplos. A edição pelo Hermes depende da sessão real do Studio; os checks deste pacote comprovam HTML, recursos e renderização.

## Origem e licença

HTML/CSS autoral do SquadOS. Arte criada e preparada com ImageGen nativo do Codex, sem tipografia incorporada. Licença Apache-2.0, preservada em LICENSE. Nenhum arquivo de fonte ou asset de terceiros é distribuído neste pacote.

## English

This template contains a single editable HTML/CSS cover at 1280×720. Copy the complete package before personalizing it; keep assets/, LICENSE and the stable slide/field IDs. The background PNG has no text. All visible titles, names, dates and footer labels are HTML text. Add more slides when requested. Local fonts and CSS fallbacks may change letter proportions across computers. preview.png is a rendering of the actual source. Example names and dates are placeholders. Open presentation.html directly; the cover uses no scripts, server or remote resources.
